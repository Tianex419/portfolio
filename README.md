# Christian Jhune T. Villapaz — Personal Portfolio

A modern, professional, and mobile-responsive personal portfolio website built with **HTML5**, **CSS3**, and **Vanilla JavaScript** only.

## Features

- Multi-page layout: About, Organizations & Volunteer, Projects, Certificates
- Responsive design (desktop, laptop, tablet, mobile)
- Sticky navigation with hamburger menu on mobile
- Smooth scrolling and scroll-reveal animations
- Image lightbox for organization and project photos
- Back-to-top button
- Accessible markup with meaningful `alt` text

## How to Open

1. Open the `portfolio` folder.
2. Double-click `index.html`, or open it in any modern browser.
3. Replace placeholder images in `images/` with your real photos (keep the same filenames).

No build tools or servers are required.

## Customization

| Item | Where to edit |
|------|----------------|
| About text | `index.html` |
| Organization captions | `organizations.html` |
| Project details & tech tags | `projects.html` |
| Certificates paragraph & list | `certificates.html` |
| Colors & typography | `css/style.css` (`:root` variables) |
| Contact / social links | Footer on each HTML page |
| Behavior (nav, lightbox, etc.) | `js/script.js` |

## Contact Placeholders

Update footer links before publishing:

- `mailto:your-email@example.com`
- Facebook, LinkedIn, and GitHub URLs

## Browser Support

Works on current versions of Chrome, Edge, Firefox, and Safari.
